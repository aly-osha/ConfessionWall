# Confession Wall (BCA Final Year Project)

An AI‑Moderated Anonymous Text Confession Platform built with the MERN stack (MongoDB, Express, React, Node.js).

## 📌 Project Overview
This repository contains a full‑stack social platform where users can post anonymous confessions, comment on content, and interact in a moderated environment. AI and community reporting power the moderation system, and administrators have tools for managing infractions.

### 🔧 Backend (folder: `backend`)
- Node.js with Express server (`server.js`)
- MongoDB database connection (`src/config/db.js`)
- Models: `User`, `Post`, `Comment`, `Report`
- Controllers & routes for users, posts, comments, reports, and admin operations
- JWT authentication, password hashing with bcrypt
- Middleware for error handling and route protection
- Seed script (`seedUsers.js`) to populate initial users

### ⚛️ Frontend (folder: `frontend`)
- React app bootstrapped with Vite
- Pages: Login, Register, Feed, Profile, SinglePost, AdminDashboard
- Simple global state via `store/authStore.js`
- API service layer (`src/services/api.js`) communicates with backend

## ✨ Key Features
- **Total anonymity** through autogenerated usernames
- **AI moderation** screens posts/comments for offensive content
- **Posting & commenting** with upvotes/downvotes and threads
- **Auto-moderation**: posts hidden after 5 reports; users banned after 3 violations
- **Admin dashboard** for user/report management
- **JWT authentication** with secure token generation
- Utilities like username generator and token helper

## 🚀 Setup Instructions

### 1. Database
1. Create a free MongoDB Atlas cluster.
2. Copy the connection URI and set credentials.

### 2. Backend
```bash
cd backend
npm install
```
Create a `.env` file with:
```env
PORT=5000
MONGO_URI=your_mongodb_connection_string_here
JWT_SECRET=super_secret_key_for_json_web_tokens
NODE_ENV=development
```
Start the server:
```bash
npm run dev
# or
node server.js
```

### 3. Frontend
```bash
cd frontend
npm install
npm run dev
```
Access the app at `http://localhost:5173` (proxying API to `http://localhost:5000`).

## 📦 Deployment Guide

### Backend – Render
1. Push to GitHub.
2. Create a Render Web Service, pointing at `backend`.
3. Build command: `npm install`; start command: `node server.js`.
4. Add environment variables (`MONGO_URI`, `JWT_SECRET`).

### Frontend – Vercel
1. Connect your GitHub repo to Vercel.
2. Set root directory to `frontend` and ensure Vite is detected.
3. Update `frontend/src/services/api.js` or environment variables with your backend URL.
